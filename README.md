# A股自设指数净值回测工具

基于 AKShare 的 A 股自定义指数（投资组合）回测与分析 Web 应用。用户定义由 A 股股票组成的投资组合（含权重和调仓计划），回测引擎根据实际历史日线价格（前复权）模拟净值表现，并与基准指数对比。

## 功能概览

### 成分股管理
- 文件导入：支持 `.xls` / `.xlsx` / `.csv` 格式，自动识别代码列、名称列、权重列。
- 手动编辑：在调仓计划中直接增删改成分股，输入股票代码和权重。
- 一键等权分配：将当前计划中的所有成分股权重均等分配。
- 一键分配剩余权重：仅修改权重为空的成分股，将剩余比例补足到 100%。
- 自动归一化（按计划开启）：修改任一成分股权重时，自动按比例调整其他成分股权重使总和恒为 100%。
- 股票代码全链路按 6 位字符串处理，保留前导零（如 `002879`），自动从各种格式中提取。

### 调仓计划管理
- 多条调仓计划，每条可独立设置生效日期和成分股/权重。
- 计划卡片可折叠展开，支持复制、删除。
- 导出/导入全套调仓计划为 JSON 文件。

### 再平衡机制
- 支持 5 种频率：仅按计划生效日、按月、按季度、按半年、自定义日期。
- 再平衡日自动将持仓权重恢复为目标权重，考虑交易成本。
- 多模式对比：自动计算用户未选择的其他标准再平衡模式下的净值曲线和指标，对比模式与主模式使用相同的交易成本参数。

### 回测引擎
- 基于 AKShare 日线前复权收盘价计算净值曲线。
- 按日模拟：每日投资组合收益 = 持仓权重 × 日收益率 + 现金仓位 × 无风险日利率。
- 权重每日随市价漂移，在再平衡日恢复为计划目标权重。

### 交易成本
- 佣金（双边）：买卖均收取，可配置费率（默认 0.025%）。
- 印花税（卖方单边）：仅卖出时收取（默认 0.05%）。
- 滑点（双边）：买卖均受影响（默认 0.1%）。
- 成本按再平衡日换手率计算，均可设为 0 忽略成本。

### 现金仓位
- 支持”允许现金仓位”模式：权重总和不足 100% 时，余额计为现金，按无风险利率计息。
- 关闭时，权重自动归一化至精确 100%。

### 缺数策略
- 停牌/缺失数据按当日收益 0 处理，资金等效留在该头寸（hold_cash）。

### 绩效指标
- 区间总收益、年化收益率、年化波动率。
- 夏普比率、索提诺比率、卡玛比率。
- 最大回撤（含起始/结束/恢复日期）。
- 胜率（日收益为正的交易日占比）。
- 年度回报表 + 月度回报热力图。

### 基准对比
- 默认基准：沪深300（000300）、中证500（000905）、上证指数（000001），仅在未选择任何基准时自动预载。
- 可在高级设置中自定义基准代码。
- 可保存多次回测结果，叠加对比不同策略的净值曲线。

### 数据可视化
- 净值曲线图（ECharts 折线图，标记再平衡日期，支持 Tooltip 查看净值、累计收益、日涨跌与持仓明细；日涨跌为当天净值相对前一交易日的变化，基准与对比回测曲线同样显示）。
- K 线图（蜡烛图）：在「净值与回撤」工具栏把「净值」切换为「K线」，即可查看组合指数的日线开高低收。OHLC 由同一批成分股日线的开盘/最高/最低/收盘按每日持仓权重合成，**收盘价与净值曲线严格一致**；Tooltip 展示开/高/低/收、涨跌幅与振幅，调仓日以竖线标注。
- K 线周期：K 线视图工具栏提供「日K / 周K / 月K / 季K / 年K」切换，默认日K。周/月/季/年 K 由同一份日线 OHLC 在前端按自然周期聚合：开盘取区间内首个交易日开盘、收盘取区间最后一个交易日收盘、最高/最低取区间极值，因此各周期的收盘价仍与净值曲线一致；节奏按 ISO 周（周一至周日）、自然月、自然季度、自然年划分，Tooltip 显示该蜡烛的实际区间（如 `2024-12-30 ~ 2024-12-31`），回测区间尚未覆盖完整个周期时标注「本期未完」。周期选择保存在 localStorage。
- K 线均线：默认叠加 MA5、MA10、MA20、MA30、MA60，「K线」视图工具栏会多出一个「均线」按钮（角标为当前显示的条数，被过滤时高亮），点开面板可逐条勾选显示/隐藏、全选/全不选/恢复默认，也可添加 1–250 的自定义周期（如 MA120）并单独删除；设置保存在浏览器 localStorage，图例与 Tooltip 同步显示各条均线数值。均线按当前周期的蜡烛根数计算（MA5 在周K 上即 5 周均线，在月K 上即 5 月均线）。
- 回撤区域图（净值曲线下方阴影标注回撤）。
- 持仓演变堆积面积图（按日展示前 15 大重仓股占比变化）。
- 多模式净值曲线对比。
- 时间轴缩放：净值/K线/回撤/超额收益与持仓演变图底部都有时间轴滑条，可拖动选段或
  用滚轮在框内缩放；四种净值视图共用同一选段，切换视图、增减基准或对比回测时
  保持不放，重新跑一次回测则回到全区间。
- 深色/浅色主题可切换；浅色主题下标签页、图标按钮和图表视图切换使用浅灰悬停背景，折叠箭头在悬停或键盘聚焦时加深，保持文字与图标清晰可辨。
- 顶栏最左侧的面板按钮可整体收起/展开左侧配置面板，让结果区占满大屏；折叠状态持久保存在浏览器，图标与提示文字随状态切换。
- 涨跌配色遵循 A 股习惯：**涨/盈利为红、跌/亏损为绿**（含指标卡、年度/月度收益、月度热力图、净值 Tooltip、回撤曲线与持仓权重变动）。该语义由 `--up` / `--down` 单独承载，与表示「状态正常/错误危险」的 `--positive` / `--danger` 解耦，因此后端状态点、删除按钮、表单报错的颜色不受影响。
- 指标说明支持鼠标悬停或键盘聚焦，气泡不受指标容器裁剪；调仓日 Tooltip 的股票代码、名称和权重统一跟随提示框文字色，深浅主题下均保持可读。

### 数据导出
- 导出净值 + 基准数据为 UTF-8 BOM CSV 文件（含日涨跌% 列）。
- 导出净值图表为 PNG 截图。

### 进度反馈
- 异步回测任务，实时显示进度条和当前阶段。
- 支持并发任务管理（环境变量 `BACKTEST_MAX_CONCURRENT` 控制上限，默认 3）。
- 每个阶段显示当前步骤/总步骤数和已用时间。

### 状态持久化
- 前端使用 localStorage 自动保存/恢复：调仓计划、回测参数、上次回测结果、已保存对比。

## 技术架构

| 层级 | 技术 |
|------|------|
| 前端 | 原生 HTML5 / CSS3 / JavaScript（无框架），ECharts 5（CDN） |
| 后端 | Python FastAPI + Uvicorn |
| 数据源 | AKShare（`stock_zh_a_hist` 主用，`stock_zh_a_hist_tx` 兜底；日线收盘价 + 开高低收） |
| 缓存 | Feather 格式文件缓存（pyarrow），按代码分文件存储 |
| 持久化 | 前端 localStorage，后端无数据库 |

## 本地运行

### 一键启动（推荐）

```bash
./start.sh
```

脚本会自动完成：检查 Python → 缺少依赖时自动 `pip install -r requirements.txt`
（必要时创建 `.venv`）→ 启动后端 → 等待服务就绪 → 打开浏览器
`http://127.0.0.1:8000/`。停止服务：在窗口里按 `Ctrl+C`，或直接关闭窗口。

- macOS：也可以在 Finder 里双击 `start.command`。
- Windows：双击 `start.bat`。

可用参数：

| 命令 | 说明 |
|------|------|
| `./start.sh` | 启动并打开 `http://127.0.0.1:8000/` |
| `./start.sh --port 8010` | 换端口启动（页面里的「后端地址」会自动跟随） |
| `./start.sh --file` | 仍然打开本地 `index.html`（保留 `file://` 下的既有本地存档） |
| `./start.sh --no-open` | 只启动服务，不打开浏览器 |
| `./start.sh --help` | 查看帮助 |

> 页面通过后端直接提供，因此不再需要手动打开 `index.html`。
> 注意：浏览器按来源（origin）隔离本地存储，`http://127.0.0.1:8000` 与
> `file://` 下的调仓计划/参数互不相通。若想沿用旧的 `file://` 存档，
> 先用 `./start.sh --file` 打开旧页面，导出调仓计划 JSON，再在默认模式下导入。

服务默认地址：`http://127.0.0.1:8000`，浏览器直接访问该地址即可打开页面
（也可继续双击 `index.html`，页面中后端地址保持默认 `http://127.0.0.1:8000`）。

### 4. 使用流程
1. **导入成分股**：上传 `xls` / `xlsx` / `csv` 文件，选择后会自动解析预览，预览确认后应用到某条调仓计划。
2. **编辑调仓计划**：手动增删改成分股与权重，支持等权分配、分配剩余权重、自动归一化。
3. **设置回测参数**：选择起止日期、调仓频率、无风险利率，可选配置交易成本和现金仓位。
4. **执行回测**：点击”执行回测”，等待进度完成。
5. **查看结果**：净值图表、绩效指标、持仓演变、年度/月度回报。

## 后端 API 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/api/health` | 健康检查，返回数据源信息 |
| `POST` | `/api/parse-components` | 解析上传的 Excel/CSV 成分股文件（`multipart/form-data`，字段名 `file`） |
| `POST` | `/api/backtest` | 同步执行回测（JSON 请求体） |
| `POST` | `/api/backtest/tasks` | 创建异步回测任务，返回 `task_id` |
| `GET` | `/api/backtest/tasks` | 列出全部回测任务（含状态、进度、耗时） |
| `GET` | `/api/backtest/tasks/{task_id}` | 获取异步任务状态、进度、耗时和结果 |
| `POST` | `/api/backtest/tasks/{task_id}/cancel` | 取消异步回测任务 |
| `GET` | `/`（及 `/index.html`、`/app.js`、`/styles.css`、`/vendor/*`） | 提供前端页面与静态资源；仅暴露这几项，`backend/` 源码与 `.cache/` 数据不可访问 |

`POST /api/backtest` 与 `POST /api/backtest/tasks` 的请求体支持 `include_ohlc: true`（默认 `false`）。
开启后会随收盘价一并拉取日线开高低收，并在结果中返回 `nav_ohlc: { dates, open, high, low, close, end_date }`；
`end_date` 是本次回测请求的结束日，前端用它判断最后一根周/月/季/年 K 是否已覆盖完整个周期
（以周末收尾的周期不算「本期未完」；法定长假使周期最后一个交易日提前时，仍可能被标为「本期未完」）。
前端「K线」视图依赖该字段，旧客户端不传时保持原来的纯收盘价路径。
周/月/季/年 K 不新增接口，由前端把 `nav_ohlc` 的日线按自然周期聚合得到；只要结果里带有 `nav_ohlc`
（本次升级后跑出的结果）即可直接切换周期，更早保存、没有该字段的结果会提示重新回测一次。
若个别成分股开高低收拉取失败，回测照常完成，该股改用收盘价近似生成蜡烛并在 `warnings` 中提示；
只有整批开高低收都无法构建时 `nav_ohlc` 才为 `null`（K 线视图提示重跑）。

> 测试：`python3 -m pytest -q`。前端 K 线逻辑用 node 驱动真实脚本；本地未安装 node 时会跳过，
> CI 或设置 `BACKTEST_REQUIRE_NODE=1` 时会因缺少 node 直接失败（避免「全绿但一条没跑」）。

> AKShare 的 `stock_zh_a_hist` 本身已返回「开盘/收盘/最高/最低」，因此无需新增第三方数据源或额外接口；
> 本项目只是在原有日线请求中保留这四个价格字段，并新增 OHLC 缓存（`stock_ohlc`）。腾讯兜底源
> `stock_zh_a_hist_tx` 同样返回 `open/close/high/low`。
>
> 组合 OHLC 是日线级近似：最高/最低由各成分股当日最高/最低按持仓权重加权得到，并不代表组合在
> 同一时刻真实触及的极值；收盘价则严格复用净值，因此 K 线的收盘与「净值」曲线逐点一致。
> 聚合周期 K 沿用同一口径：区间最高/最低是区间内日线最高/最低的极值，区间收盘是区间最后一个交易日的组合收盘。

### 异步任务轮询示例
```javascript
// 创建任务
const { task_id } = await fetch(“/api/backtest/tasks”, { method: “POST”, body: JSON.stringify(request) }).then(r => r.json());
// 轮询进度
const poll = setInterval(async () => {
  const task = await fetch(`/api/backtest/tasks/${task_id}`).then(r => r.json());
  console.log(task.progress_pct, task.stage_label, task.elapsed_seconds);
  if (task.status === “completed” || task.status === “failed”) {
    clearInterval(poll);
    if (task.result) console.log(“结果:”, task.result);
  }
}, 500);
```

## 数据缓存

- 股票价格数据和基准数据以 Feather 格式缓存在 `.cache/akshare/` 目录下。
- 收盘价缓存在 `stock_close/`；K 线用的开高低收缓存在 `stock_ohlc/`（各带 `*_meta/` 区间元数据）。
- 收盘价缓存时若 AKShare 同一次响应带回开高低收，会顺带写入 OHLC 缓存，正常不会产生第二次请求；
  只有旧版仅收盘价缓存需要补齐 OHLC 时，才会按缺失区间单独拉取一次。
- **升级后首次回测**需要为存量的收盘价缓存补拉一次 OHLC，抓取耗时约为原来的两倍；之后再回测与以前一致。
- OHLC 缓存写入采用「临时文件 + `os.replace`」原子替换，进程崩溃不会留下截断的 Feather 文件；
  若检测到元数据声称已缓存但 Feather 缺失/损坏，会自动重新拉取而不是静默返回空 K 线。
- 服务启动时自动将旧版 CSV 缓存转换为 Feather 并清理残留（Feather 已存在时直接删除 CSV，数据不丢失）。
- 每个代码对应一个 `.feather` 文件，附带范围元数据（JSON）跟踪已缓存的日期区间。
- 仅获取缺失日期范围的数据，避免重复 API 调用。
- 请求区间包含当天时，交易时段内使用进程内短 TTL 缓存；15:05 之后成功获取的当天行情才写入长期 Feather 缓存。
- 通过 AKShare 交易日历（进程内 TTL 缓存）判断当天是否开市，法定节假日不会对每只成分股发起无效的当日行情请求。
- `.cache/` 目录已加入 `.gitignore`。

## 注意事项
- 需要能够访问 AKShare 行情源的网络环境。
- 首次回测需拉取全量历史数据，耗时较长；后续回测仅拉取增量数据。
- Excel/CSV 导入会自动识别表头行，权重列支持百分比和数值两种格式。
- 文件解析时若权重合计略超 100%（如因四舍五入），预览会自动按比例规整；回测时使用高精度 Decimal 修正保证总和精确。
